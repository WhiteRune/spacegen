Task: Fact-check claims against candidate documents.
Integration Context: Called by `fact_check_claims()` in the pipeline. Must output a strict JSON array of dicts. Be robust—`extract_json_from_response` will parse your output.

Inputs:
- claims: array of {claim_id, text}
- candidate_docs: array of documents {url, title, excerpt}

Instruction:
For each claim, check whether it is directly supported, partially supported, contradicted, or not found in candidate_docs. Return a valid JSON array of results, each with fields:
- claim_id (string)
- supported: "true" | "false" | "uncertain"
- best_source_url (string or null)
- excerpt (string or null)
- confidence (float 0-1)
- note (brief explanation string)

Scoring rules:
- supported="true" only if a doc contains a direct statement or data matching the claim.
- "uncertain" if partial or contextual support exists.
- "false" if a doc directly contradicts the claim.
- If no doc matches, set supported="false", best_source_url=null, confidence=0, note="needs_source" or "not_found".
Ensure the output is a pristine JSON array `[...]`.
