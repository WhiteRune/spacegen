OpenRouter curl example & Pipeline Integration Reference:

This is a demonstration of how `OpenRouterClient` in `shared_utils.py` interacts with the API under the hood using headers.

curl -X POST "https://api.openrouter.ai/v1/chat/completions" \
  -H "Authorization: Bearer $OPENROUTER_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model":"[from OPENROUTER_MODEL env var]",
    "messages":[
      {"role":"system","content":"[loaded from Prompts/system.txt]"},
      {"role":"user","content":"[loaded from Prompts/*.txt template, formatted with vars]"}
    ],
    "max_tokens":1000
    // "extra_body": {"reasoning": {"enabled": true}} // If enable_reasoning flag is passed in CLI
  }'

Notes for context generation:
- The pipeline securely streams outputs for TTS in `voice_generator.py`.
- Keep API interactions aligned with exponential backoff capabilities detailed in `OpenRouterClient._call_api()`.
