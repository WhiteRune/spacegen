# Video Generation Pipeline Orchestrator

A Python-based automation tool that orchestrates a video generation pipeline using the **OpenAI SDK** with **OpenRouter** backend and **DeepSeek v4 Flash** model.

## Overview

This tool implements a multi-step pipeline for generating educational video content:

1. **Retrieval Queries**: Generate 5 ranked search queries for the topic
2. **Outline**: Create a scene-by-scene outline for the video
3. **For each scene**:
   - **Script with Citations**: Generate narration with inline source citations
   - **Fact-Checker**: Verify claims against provided documents
   - **SSML Generator**: Convert narration to SSML with timing hints

## Requirements

- Python 3.10+
- OpenRouter API key (get at https://openrouter.ai)
- Prompt templates in `Prompts/` directory:
  - `system.txt`
  - `retrieval_queries.txt`
  - `outline.txt`
  - `script_with_citations.txt`
  - `fact_checker.txt`
  - `ssml_generator.txt`

  ],

Documents can be keyed by:

If a scene has no matching documents, claims are marked as `needs_source` with confidence 0.

## Output Files

Generated in the output directory (default: `./output`):

- **`video_package.json`**: Final video package with all scenes, narration, SSML, and fact-checked claims
- **`orchestration_log.json`**: Detailed statistics per scene (doc count, claim counts, support status)
- **`outline.json`**: Scene outline generated in step 2
- **`scene_<id>_script.json`**: Intermediate files for each scene (for debugging)
- **`narration_draft.txt`**: Extracted full narration transcript (generated by `extract_narration.py`)
- **`YOUTUBE_REFORMAT_TEMPLATE.txt`**: Template for reformatting narration to YouTube hook format

## Troubleshooting

### API Rate Limiting (429)

The script implements exponential backoff with up to 3 retries. If you still hit rate limits:
- Check OpenRouter account quotas at https://openrouter.ai/account/usage
- Reduce `--scenes-count`
- Wait between runs
- Consider upgrading your OpenRouter plan

### Authentication Error

Make sure your OPENROUTER_API_KEY is valid:
```powershell
$env:OPENROUTER_API_KEY = "sk-or-v1-your-actual-key"
```

Get your key at https://openrouter.ai/keys

### DNS/Connection Issues

If you see `NameResolutionError` or connection timeouts:
- Check internet connectivity: `ping google.com`
- Verify DNS: `nslookup openrouter.ai`
- Try disabling VPN/proxy temporarily
- Check if firewall blocks openrouter.ai

### Model Not Found

If you get a 404 for the model:
- Verify model name is correct: `deepseek/deepseek-v4-flash`
- Check available models at https://openrouter.ai/docs/models
- Ensure you have credit on your OpenRouter account

## Narration Extraction & Reformatting

### Extract Narration to Text File

After generating the video package, extract the full narration transcript:

```bash
python extract_narration.py --video-package output/video_package.json --output output/narration_draft.txt
```

This creates:
- **`narration_draft.txt`**: Full transcript with scene markers and timing
- Includes helpful tips for YouTube reformatting

### Reformat for YouTube (Hook Format)

Use the included template to reformat narration for maximum viewer engagement:

```bash
# Template shows the structure:
# 1. Hook (0-3s) - Stop them scrolling with shocking fact/question
# 2. Promise (3-8s) - Preview what they'll learn
# 3. Explain #1 (8-25s) - What is it? (with analogies)
# 4. Explain #2 (25-40s) - How did it form? (dramatic origin story)
# 5. Explain #3 (40-55s) - Why care? (make it relevant)
# 6. Call to Action (55-60s) - Subscribe/next video
```

Edit `output/YOUTUBE_REFORMAT_TEMPLATE.txt` to see detailed examples and write your own version.

**Key principles:**
- First 5 seconds: Stop the scroll
- Use analogies instead of abstractions
- Build tension → release → new tension
- Direct address ("you", "your")
- Short sentences for pacing
- End with clear engagement hook

## Voice Generation with Gemini TTS

Generate professional audio narration using Google's Gemini Text-to-Speech model via OpenRouter. The voice generation system supports 30 professional voices and advanced prompting for educational content.

### Quick Start: Generate Voice Narration

**Via GUI (Easiest):**
```bash
python gui_launcher.py
```
Then click "Generate Voice" button. Choose voice, set speed, and click generate.

**Via Command Line:**
```bash
python voice_generator.py \
    --narration ./output/narration_draft_youtube.txt \
    --voice Charon \
    --speed 1.0 \
    --output-dir ./output/voice_over
```

**With Narrator Prompt (Advanced):**
```bash
python voice_generator.py \
    --narration ./output/narration_draft_youtube.txt \
    --narrator-prompt ./Prompts/narrator_prompt_educational.txt \
    --voice Charon \
    --speed 1.0
```

### Advanced: Narrator Prompts for Educational Content

Three professional narrator prompts are provided, each optimized for different educational styles:

1. **narrator_prompt_educational.txt** — General educational content (default)
   - Balanced, engaging narrator with natural pacing
   - Best for: Science, history, tutorials, how-to content

2. **narrator_prompt_technical.txt** — Technical deep-dives
   - Precise, authoritative, measured delivery
   - Best for: Programming, advanced topics, professional content

3. **narrator_prompt_motivational.txt** — Personal development & wellness
   - Warm, inspiring, conversational tone
   - Best for: Self-improvement, psychology, lifestyle education

**Full Guide:** See [`NARRATOR_PROMPTS_GUIDE.md`](./NARRATOR_PROMPTS_GUIDE.md) for detailed usage, custom prompt creation, and audio tag reference.

### Voice Generation Output

Generated files are saved in `output/voice_over/` by default:
- `001.pcm` through `NNN.pcm` — Raw PCM audio (intermediate)
- `001.mp3` through `NNN.mp3` — Final MP3 files (one per sentence)
- Summary display showing: total files, combined duration, output directory

**How Narrator Prompts Are Applied:**

When you select a narrator prompt (Educational, Technical, Motivational), it acts as the **base instruction** for audio generation:

```
narration_draft_youtube.txt (5 sentences)
    ↓
    ├─ Sentence 1 + Educational Prompt → 001.mp3 ✓
    ├─ Sentence 2 + Educational Prompt → 002.mp3 ✓
    ├─ Sentence 3 + Educational Prompt → 003.mp3 ✓
    ├─ Sentence 4 + Educational Prompt → 004.mp3 ✓
    └─ Sentence 5 + Educational Prompt → 005.mp3 ✓

Result: 5 MP3s with consistent narrator voice, tone, and pacing
```

Each sentence uses the narrator prompt as its performance foundation, ensuring unified voice character across all generated audio.

### Adjust Speech Speed

Use the `--speed` parameter (0.5 to 2.0):
- `0.5` = Half speed (clear, measured delivery)
- `1.0` = Normal speed (default)
- `1.5` = 1.5x faster (energetic, rapid)
- `2.0` = Double speed (maximum energy)

Example:
```bash
python voice_generator.py \
    --narration ./output/narration_draft_youtube.txt \
    --voice Puck \
    --speed 1.2
```

### Troubleshooting Voice Generation

**Issue:** "Internal Server Error (500)" with retry
- **Cause:** OpenRouter Gemini TTS service temporarily unavailable
- **Solution:** Wait 15 seconds (auto-retry), then try again

**Issue:** Audio quality is robotic
- **Cause:** No narrator prompt applied
- **Solution:** Use `--narrator-prompt` with appropriate prompt file

**Issue:** MP3 conversion fails
- **Cause:** ffmpeg not installed
- **Solution:** Install ffmpeg: `choco install ffmpeg` (Windows) or `brew install ffmpeg` (Mac)

**Issue:** Pacing too fast or slow
- **Cause:** Speech speed parameter too high/low
- **Solution:** Adjust `--speed` parameter (default 1.0)
