# Video Generation Pipeline Orchestrator

A Python-based automation tool that orchestrates a video generation pipeline using the **OpenAI SDK** with **OpenRouter** backend and **DeepSeek v4 Flash** model.

## Overview

This tool implements a multi-step pipeline for generating educational video content:

1. **Retrieval Queries**: Generate 5 ranked search queries for the topic
2. **Outline**: Create a scene-by-scene outline for the video
3. **For each scene**:
   - **Script with Citations**: Generate narration with inline source citations
   - **Fact-Checker**: Verify claims against provided documents
   - **SSML Generator**: Convert narration to SSML with timing hints

## Requirements

- Python 3.10+
- OpenRouter API key (get at https://openrouter.ai)
- Prompt templates in `Prompts/` directory:
  - `system.txt`
  - `retrieval_queries.txt`
  - `outline.txt`
  - `script_with_citations.txt`
  - `fact_checker.txt`
  - `ssml_generator.txt`

### Fastest Way (GUI)


Click "Generate Video Package" button with default or custom parameters.


### Expected Retrieved Documents JSON Schema

```json
{
  "1": [
    {
      "url": "https://example.com/article1",
      "title": "About Neutron Stars",
      "excerpt": "Neutron stars are collapsed cores of massive stars..."
    },
    {
      "url": "https://example.com/article2",
      "title": "Formation of Neutron Stars",
      "excerpt": "Neutron stars form when massive stars undergo supernova..."
    }
  ],
  "2": [
    {
      "url": "https://example.com/article3",
      "title": "Properties of Neutron Stars",
      "excerpt": "Neutron stars are extremely dense..."
    }
  ],
  "keywords_scene_3": [
    {
      "url": "https://example.com/article4",
      "title": "Pulsars",
      "excerpt": "Some neutron stars emit radio pulses..."
    }
  ]
}
```

Documents can be keyed by:
- Scene ID (string): `"1"`, `"2"`, etc.
- Scene keywords: `"neutron stars"`, `"pulsars"`, etc.

If a scene has no matching documents, claims are marked as `needs_source` with confidence 0.

## Output Files

Generated in the output directory (default: `./output`):

- **`video_package.json`**: Final video package with all scenes, narration, SSML, and fact-checked claims
- **`orchestration_log.json`**: Detailed statistics per scene (doc count, claim counts, support status)
- **`outline.json`**: Scene outline generated in step 2
- **`scene_<id>_script.json`**: Intermediate files for each scene (for debugging)
- **`narration_draft.txt`**: Extracted full narration transcript (generated by `extract_narration.py`)
- **`YOUTUBE_REFORMAT_TEMPLATE.txt`**: Template for reformatting narration to YouTube hook format

## Troubleshooting

### API Rate Limiting (429)

The script implements exponential backoff with up to 3 retries. If you still hit rate limits:
- Check OpenRouter account quotas at https://openrouter.ai/account/usage
- Reduce `--scenes-count`
- Wait between runs
- Consider upgrading your OpenRouter plan

### Authentication Error

Make sure your OPENROUTER_API_KEY is valid:
```powershell
$env:OPENROUTER_API_KEY = "sk-or-v1-your-actual-key"
```

Get your key at https://openrouter.ai/keys

### DNS/Connection Issues

If you see `NameResolutionError` or connection timeouts:
- Check internet connectivity: `ping google.com`
- Verify DNS: `nslookup openrouter.ai`
- Try disabling VPN/proxy temporarily
- Check if firewall blocks openrouter.ai

### Model Not Found

If you get a 404 for the model:
- Verify model name is correct: `deepseek/deepseek-v4-flash`
- Check available models at https://openrouter.ai/docs/models
- Ensure you have credit on your OpenRouter account

## Narration Extraction & Reformatting

### Extract Narration to Text File

After generating the video package, extract the full narration transcript:

```bash
python extract_narration.py --video-package output/video_package.json --output output/narration_draft.txt
```

This creates:
- **`narration_draft.txt`**: Full transcript with scene markers and timing
- Includes helpful tips for YouTube reformatting

### Reformat for YouTube (Hook Format)

Use the included template to reformat narration for maximum viewer engagement:

```bash
# Template shows the structure:
# 1. Hook (0-3s) - Stop them scrolling with shocking fact/question
# 2. Promise (3-8s) - Preview what they'll learn
# 3. Explain #1 (8-25s) - What is it? (with analogies)
# 4. Explain #2 (25-40s) - How did it form? (dramatic origin story)
# 5. Explain #3 (40-55s) - Why care? (make it relevant)
# 6. Call to Action (55-60s) - Subscribe/next video
```

Edit `output/YOUTUBE_REFORMAT_TEMPLATE.txt` to see detailed examples and write your own version.

**Key principles:**
- First 5 seconds: Stop the scroll
- Use analogies instead of abstractions
- Build tension → release → new tension
- Direct address ("you", "your")
- Short sentences for pacing
- End with clear engagement hook
